# 민감한 파일은 Qwen 이 먼저 읽는다

원문은 사내 Qwen(HAI)만 읽는다. Claude(나)는 가린 글이나 Qwen 의 답만 본다.

## 고르는 법
- **원문 전체가 필요 없다**(요약, 특정 조항·항목 찾기, 목록 뽑기, 예/아니오 판단) → `hai_ask_file`
- **개수 세기·합계·통계**(대장·명단 집계) → `hai_mask_file` 로 받아 내가 센다(필요하면 코드로). Qwen 은 긴 글의 개수를 자주 틀린다
- **글을 같이 다듬거나 분석해야 한다**(보고서 초안, 표 정리, 비교) → `hai_mask_file` 로 가린 본문을 받아 작업
- **결과를 실명으로 남겨야 한다** → 자리표시가 든 결과물을 `hai_restore` 로 로컬 파일에 저장. 원래 값을 나에게 보여 달라고 하지 않는다

## 지킬 것
- 민감한 파일은 Read·Grep·cat 으로 열지 않는다. 보호 폴더 훅에 막히면 우회하지 말고 HAI 도구를 쓴다.
- 자리표시([이름1], [휴대전화2])는 그대로 두고 작업한다. 원래 값을 추측하거나 채워 넣지 않는다.
- 결과에 실명·연락처처럼 보이는 게 남아 있으면 사용자에게 알리고 `extra` 로 유형을 더해 다시 가린다(예: `{"거래처명":"계약 상대 회사 이름"}`).
- HAI 오류(키 없음·연결 안 됨)가 나면 원문을 직접 읽어 대신하지 않는다. `hai_status` 로 원인을 보고 사용자에게 알린다.
- 같은 문서를 여러 번 가릴 때는 앞 결과의 `mask_id` 를 넘겨 자리표시 번호를 맞춘다.
