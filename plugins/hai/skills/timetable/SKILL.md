# EVS 타임테이블 작성

인자: $ARGUMENTS (년월. 비우면 지난달)

한국어로, 짧게. 사용자는 비개발자일 수 있다 — 용어 대신 화면 이름으로 안내한다.

## 0. 내 규칙 불러오기
`~/.hai-mcp/timetable-rules.md` 를 Read 로 연다(사용자마다 하나, 이 PC 에만 있다).
- **없으면 처음 설정** — 아래를 하나씩 묻고 파일로 저장한 뒤, 저장한 내용을 보여 준다.
  1. 소속 부서와 EVS 업무코드: EVS 타임테이블 등록 화면의 업무코드 찾기에서 자주 쓰는 코드·업무명(예: `GA_100 총무업무`). 화면을 캡처해 주면 hai_chat(images)로 읽어도 된다.
  2. 업무별로 어느 법인에 시간을 넣는지: 예 "총무 일은 헥토 8시간", "헬프데스크 문의는 그날 문의 법인 건수 비율", "공통 업무는 법인별 고정 비율(헥토 50 · 이노 20 …)".
  3. 그달 한 일을 무엇으로 확인하는지: 업무일지·주간업무보고 파일, 캘린더, 문의 대장 엑셀, 기억으로 직접 말하기 중에서.
  4. 하루 기준 시간(기본 8.0)과 업무상세를 어떻게 쓰는지(짧게 그날 한 일).
- **있으면** 그대로 따른다. 사용자가 이번에 바꾸라고 하면 파일도 고친다.

## 1. 그달 양식 받기
사용자에게: "EVS → 타임테이블 등록 → 신규 → 년월 고르기 → 양식다운로드 를 눌러 받은 파일 경로를 알려 주세요(보통 다운로드 폴더)."
양식에는 그달 근무일(휴일 제외)이 이미 한 줄씩 들어 있다. 날짜는 양식을 따른다.

## 2. 그달 한 일 모으기
규칙의 3번 출처로 날짜별 한 일을 모은다.
- 문서(업무일지·주간보고·대장 엑셀)는 `hai_ask_file`·`hai_ask_files` 로 "날짜별로 한 일·건수를 표로" 묻는다. 개인정보가 든 원문을 Read 로 직접 열지 않는다.
- 비는 날은 추측해 채우지 말고 모아서 한 번에 묻는다("10/9, 10/17 은 무엇을 하셨나요? 같은 일이 매일 반복이면 그렇게 말해 주세요").
- 매일 같은 일을 하는 사람이면 한 줄 규칙으로 전체를 채워도 된다.

## 3. 초안 표 보여 주기
| 일자 | 업무코드 | 업무명 | 업무상세 | 법인별 시간(0이 아닌 것만) |
- 하루 합계가 기준 시간(기본 8.0)과 맞는지, 0.1 단위인지 확인한다. 비율로 나누면 반올림 차이를 가장 큰 법인에서 맞춘다.
- 맨 아래에 법인별 합계, 근거(어떤 파일·말씀으로 정했는지), 확인이 필요한 날을 적는다.
- "이대로 엑셀을 채울까요?" 하고 기다린다.

## 4. 양식 채우기
승인하면 `hai_timetable_fill(template, rows)` 를 부른다. 결과의 빈 날·8시간이 아닌 날이 있으면 알린다.
그리고 안내한다:
1. EVS 타임테이블 등록 화면에서 같은 년월을 고른 채로 **Excel 업로드** → 저장된 파일 선택
2. 표가 초안과 같은지 확인 → **저장** → **확정**(확정은 본인이 직접)
3. 업로드에서 "올바르지 않은 업무코드"가 나오면, 년월을 먼저 고르고 신규 화면에서 다시 올린다. 그래도 나오면 그 코드가 부서 업무코드 목록에 있는지 확인한다.

## 하지 않는 것
- EVS 에 직접 저장·확정하지 않는다. 사용자 대신 버튼을 누르지 않는다.
- 규칙 파일 밖으로 사용자의 규칙을 보내지 않는다.
