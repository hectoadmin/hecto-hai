# HAI 사용 안내

처음 쓰는 사람(비개발자 포함)에게 안내한다. 한국어로, 짧게, 결론 먼저.

## 1. 연결 점검
`hai_status` 를 먼저 부르고 결과에 따라 안내한다.
- **hai_status 도구가 아예 없음** → 서버가 안 뜬 것이다. 대개 Node.js 가 없다 → https://nodejs.org 에서 LTS 설치 파일을 받아 "다음"만 눌러 설치하고 Claude Code 를 다시 시작(Windows 에서 검은 창이 편하면 cmd·PowerShell 에 `winget install OpenJS.NodeJS.LTS`). 모르겠으면 `/mcp` 화면에서 hai 의 오류를 보라고 안내한다.
- **파일 읽기·명령이 모두 "훅 오류"로 막힘** → 보호 훅이 돌지 못한 것이다(대개 Node.js 없음). 안전하게 막아 둔 상태이니 위처럼 Node.js 를 설치하고 다시 시작하라고 안내한다.
- **연결: 없음 / 로그인이 필요합니다·끊겼습니다** → `hai_login` 을 바로 부른다. 브라우저가 열리면 헥토 이메일을 넣고 웍스로 온 인증번호를 넣으면 끝이라고 한 줄 알려 준다. 개인 키는 필요 없다.
- **연결: 개인 키 · 키가 틀림** → `hai_login` 으로 로그인하면 키 없이 쓸 수 있다고 안내하고, 원하면 부른다.
- **연결 안 됨** → 로그인 방식이면 인터넷 연결을, 개인 키 방식이면 사내망을 확인하라고 안내한다.
- **연결됨** → 2로. 안 되는 서비스가 있으면 그 줄만 짚어 준다.
- **크롬 확장: 연결 안 됨** → 사내 화면을 쓰려는 사람에게만 안내한다: 담당자에게 사용 신청을 하고 설치 파일을 받아 평소 크롬에 설치, 패널에서 로그인, 읽을 사이트마다 "이 사이트 허용", 패널의 "닫혀 있어도 바로 실행"을 켠다. 자세한 순서는 https://hectoadmin.github.io/hecto-hai/install 의 "사용 전 해두면 좋은 것". 파일·녹음 처리와 폴더 파일 분류(`/hai:files`)는 확장 없이 된다고 덧붙인다.

로그인은 기간 제한 없이 유지된다(로그아웃 `hai_logout`·퇴사·관리자 차단 때만 끊긴다). 로그인하면 회사 밖에서도 된다.

## 3. 알아 둘 것
- 사내 AI 는 **개수 세기·합계에 약합니다.** 대장 집계는 "가려서 읽고 Claude 가 세 줘"라고 하세요.
- 가리기는 **자동이라 놓칠 수 있습니다.** 중요한 문서는 결과를 한 번 훑어보세요. "거래처명도 가려줘"처럼 더할 수 있습니다.
- 되는 파일: 문서 txt·md·csv·pdf·docx·xlsx·hwpx, 사진 png·jpg, 녹음 wav·mp3·m4a(60분까지). **옛 hwp·xls 는 hwpx·xlsx·PDF 로 저장**해서.
- **개인정보가 보이는 캡처는 채팅에 붙여 넣지 않습니다**(그러면 Claude 에 그대로 갑니다). 캡처만 하고 "클립보드 캡처"라고 말하면 사내 AI 가 클립보드에서 바로 읽습니다 — 파일을 만들지 않아 저장하면 DRM 이 걸리는 PC 에서도 됩니다.
- **보호 폴더**(플러그인 설정 `protected_dirs`)를 정해 두면 그 폴더 파일은 Claude 가 실수로도 직접 열지 못합니다. 인사·계약 폴더에 권장.
- 받아쓰기·OCR 결과(원문)는 **원문 결과 폴더**(기본: 내 문서 폴더의 `HAI 원문`, 위치는 `hai_status` 에 나옴)에 모입니다. Claude 는 이 폴더도 열지 못합니다.
- 더 확실하게 막으려면 **`/hai:protect`** — Mac 은 운영체제 수준(샌드박스)에서 보호 폴더·원문 결과 폴더 읽기를 막습니다. `hai_status` 에 "샌드박스: 꺼짐" 이 나오면 권한다.
- **Windows** 는 샌드박스가 없어 보호 훅(명령 글자 검사)이 막습니다. 그래서 ① Claude 가 실행하려는 명령에 "항상 허용"을 누르지 말고 한 번씩 확인하고 ② 인사·계약 폴더 **안에서** Claude 를 시작하지 말라고 짧게 덧붙인다. `/hai:protect` 는 Windows 에서 기본 도구 차단 규칙을 더해 준다.
- 경로는 `C:\Users\이름\Documents\계약` 처럼 탐색기 주소창 그대로 붙여 넣어도 됩니다.
- 실명 결과 파일도 Claude 가 다시 열지 못하게 막혀 있습니다. 확인은 직접 여세요.

## 4. 마무리
