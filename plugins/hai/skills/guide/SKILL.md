# HAI 사용 안내

처음 쓰는 사람(비개발자 포함)에게 안내한다. 한국어로, 짧게, 결론 먼저.

## 1. 연결 점검
`hai_status` 를 먼저 부르고 결과에 따라 안내한다.
- **hai_status 도구가 아예 없음** → 키를 아직 안 넣어 서버가 안 뜬 것이다. "/plugin 에서 hai 를 고르고 설정(configure)에 개인 HAI 키를 넣은 뒤 Claude Code 를 다시 시작하세요."
- **키 없음** → "/plugin 에서 hai 를 고르고 설정에 개인 HAI 키를 넣으세요. 키는 각자 발급받습니다(발급 창구: 사내 AI 담당 — 확인 필요)."
- **키가 틀림(401·403)** → 키를 다시 발급받아 넣으라고 안내.
- **연결 안 됨** → 사내망·VPN 에서만 된다고 안내.
- **연결됨** → 2로.

## 2. 할 수 있는 것 (이 표를 그대로 보여 준다)

| 하고 싶은 일 | 이렇게 말하면 됩니다 | 원문이 Claude 에 가나요? |
|---|---|---|
| 민감한 문서 요약 | "~/Documents/계약/임대차.pdf 를 HAI 로만 읽고 계약 기간·해지 조건 정리해줘" | 아니요. Qwen 만 읽고 답만 옵니다 |
| 개인정보를 가리고 Claude 와 작업 | "인사평가.docx 를 가려서 읽고 보고서 초안 써줘" | 가린 글만 갑니다(이름 → [이름1]) |
| 가린 결과를 실명으로 저장 | "방금 초안을 원래 이름으로 바꿔서 ~/Desktop/보고서.md 로 저장해줘" | 아니요. 내 PC 파일에만 저장 |
| 사내 AI 에 바로 질문·번역 | "HAI 한테 이 문장 공문체로 다듬어 달라고 해줘" | 이미 Claude 가 본 글이라 상관없음 |

## 3. 알아 둘 것
- Qwen 은 **개수 세기·합계에 약합니다.** 대장 집계는 "가려서 읽고 Claude 가 세 줘"라고 하세요.
- 가리기는 **자동이라 놓칠 수 있습니다.** 중요한 문서는 결과를 한 번 훑어보세요. 놓친 게 있으면 "거래처명도 가려줘"처럼 말하면 더 가립니다.
- 되는 파일: txt·md·csv·json·pdf·docx. **hwp·xlsx 는 PDF·CSV 로 저장해서** 쓰세요. 스캔 이미지 PDF 는 글자를 못 읽습니다.
- **보호 폴더**를 정해 두면(플러그인 설정 `protected_dirs`) 그 폴더 파일은 Claude 가 실수로도 직접 열지 못합니다. 인사·계약 폴더에 권장.
- 실명으로 되돌리기는 같은 세션(12시간) 안에서만 됩니다.

## 4. 마무리
"해 볼 파일이 있으면 경로를 알려 주세요" 한 줄로 끝낸다. 예시를 길게 늘어놓지 않는다.
