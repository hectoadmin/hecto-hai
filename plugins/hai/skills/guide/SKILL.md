# HAI 사용 안내

처음 쓰는 사람(비개발자 포함)에게 안내한다. 한국어로, 짧게, 결론 먼저.

## 1. 연결 점검
`hai_status` 를 먼저 부르고 결과에 따라 안내한다.
- **hai_status 도구가 아예 없음** → 서버가 안 뜬 것이다. 원인은 둘 중 하나: ① 키를 아직 안 넣음(키가 없으면 Claude Code 가 서버를 띄우지 않는다) → 아래 "키 받기" 후 "/plugin 에서 hai 를 골라 설정(configure)에 키를 넣고 Claude Code 를 다시 시작하세요" ② Node.js 가 없음 → Windows 는 PowerShell 에서 `winget install OpenJS.NodeJS.LTS`, Mac 은 https://nodejs.org 에서 LTS 설치 후 Claude Code 를 다시 시작. 어느 쪽인지 모르면 `/mcp` 화면에서 hai 의 오류를 보라고 안내한다.
- **파일 읽기·명령이 모두 "훅 오류"로 막힘** → 보호 훅이 돌지 못한 것이다(대개 Node.js 없음). 안전하게 막아 둔 상태이니 위 ②처럼 Node.js 를 설치하고 다시 시작하라고 안내한다.
- **키가 틀림** → 포털에서 새로 발급해 다시 넣으라고 안내.
- **연결 안 됨** → 사내망에서만 된다고 안내.
- **연결됨** → 2로. 안 되는 서비스가 있으면 그 줄만 짚어 준다.

키 받기: HAI 포털 https://hai-gateway.idc.hectoai.co.kr/ 에서 헥토 이메일로 회원가입 → 로그인 → 오른쪽 위 "API 키 관리" → 새 키 발급(hai- 로 시작). 키는 남에게 주지 않는다.

## 2. 할 수 있는 것 (이 표를 그대로 보여 준다)

| 하고 싶은 일 | 이렇게 말하면 됩니다 | 쓰는 사내 AI |
|---|---|---|
| 민감한 문서 요약·조항 찾기 | "임대차.pdf 를 HAI 로만 읽고 해지 조건 정리해줘" | Qwen |
| 개인정보 가리고 Claude 와 작업 | "인사평가.docx 를 가려서 읽고 보고서 초안 써줘" | Qwen(이름·주소 찾기) |
| 엑셀 명단 집계 | "주차등록.xlsx 가려서 읽고 부서별 인원 세줘" | 열 단위 가리기 |
| 회의 녹음 → 회의록 | "/hai:minutes 회의.m4a" | Whisper · Qwen3-ASR |
| 스캔 계약서·사진 읽기 | "스캔본.pdf 에서 계약 기간만 뽑아줘" | PaddleOCR |
| 스캔본을 고칠 수 있는 워드로 | "스캔본.pdf 워드 파일로 바꿔줘" | PaddleOCR(docx) |
| 폴더 문서 모아 보기 | "계약서 폴더 전부 만기일·자동갱신 표로" | Qwen |
| 내 문서에서 찾기 | "~/Documents/계약 에서 위약금 조항 찾아줘" | KURE(한국어 검색) |
| 사진·차트 설명 | "이 사진 뭐가 문제인지 HAI 한테 물어봐줘" | Gemma |
| 결과를 실명으로 저장 | "초안을 실명으로 바꿔 ~/Desktop/보고서.md 로" | 내 PC 에만 저장 |

원문은 **사내 AI 만 읽고**, Claude 에는 가린 글이나 답만 갑니다.

## 3. 알아 둘 것
- 사내 AI 는 **개수 세기·합계에 약합니다.** 대장 집계는 "가려서 읽고 Claude 가 세 줘"라고 하세요.
- 가리기는 **자동이라 놓칠 수 있습니다.** 중요한 문서는 결과를 한 번 훑어보세요. "거래처명도 가려줘"처럼 더할 수 있습니다.
- 되는 파일: 문서 txt·md·csv·pdf·docx·xlsx·hwpx, 사진 png·jpg, 녹음 wav·mp3·m4a(60분까지). **옛 hwp·xls 는 hwpx·xlsx·PDF 로 저장**해서.
- **보호 폴더**(플러그인 설정 `protected_dirs`)를 정해 두면 그 폴더 파일은 Claude 가 실수로도 직접 열지 못합니다. 인사·계약 폴더에 권장.
- 받아쓰기·OCR 결과(원문)는 **원문 결과 폴더**(기본: 내 문서 폴더의 `HAI 원문`, 위치는 `hai_status` 에 나옴)에 모입니다. Claude 는 이 폴더도 열지 못합니다.
- 더 확실하게 막으려면 **`/hai:protect`** — Mac 은 운영체제 수준(샌드박스)에서 보호 폴더·원문 결과 폴더 읽기를 막습니다. `hai_status` 에 "샌드박스: 꺼짐" 이 나오면 권한다.
- **Windows** 는 샌드박스가 없어 보호 훅(명령 글자 검사)이 막습니다. 그래서 ① Claude 가 실행하려는 명령에 "항상 허용"을 누르지 말고 한 번씩 확인하고 ② 인사·계약 폴더 **안에서** Claude 를 시작하지 말라고 짧게 덧붙인다. `/hai:protect` 는 Windows 에서 기본 도구 차단 규칙을 더해 준다.
- 경로는 `C:\Users\이름\Documents\계약` 처럼 탐색기 주소창 그대로 붙여 넣어도 됩니다.
- 실명 결과 파일도 Claude 가 다시 열지 못하게 막혀 있습니다. 확인은 직접 여세요.

## 4. 마무리
"해 볼 파일이 있으면 경로를 알려 주세요" 한 줄로 끝낸다.
