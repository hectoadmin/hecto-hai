# 민감한 문서 처리

인자: $ARGUMENTS

1. 첫 단어(따옴표 안이면 그 전체)를 파일 경로로, 나머지를 할 일로 본다. 할 일이 없으면 "핵심 내용과 날짜·금액·의무 사항 요약"으로 한다.
2. 할 일이 요약·찾기·목록·판단이면 `hai_ask_file(path, instruction)` 한 번으로 끝낸다.
   초안 작성·다듬기·비교처럼 글을 같이 만져야 하면 `hai_mask_file(path)` 로 가린 본문을 받아 작업한다.
3. 결과를 보여 줄 때 맨 위에 한 줄: `원문은 사내 Qwen 만 읽었습니다 · 가린 것: …`
4. 결과물에 자리표시가 있고 사용자가 파일로 원하면 `hai_restore` 로 저장하겠냐고 한 줄 묻는다.
5. 오류가 나면 `hai_status` 로 원인을 확인해 알린다. 원문을 Read 로 열어 대신하지 않는다.
