# 설치

**Node.js 를 깔고, Claude Code 에 한 줄 붙여넣고, 헥토 이메일로 로그인하면 끝입니다.** Windows(WSL 없이)와 Mac 모두 됩니다.

준비물:

- Claude Code 2.1.295 이상
- 헥토 이메일 — 로그인할 때 씁니다(웍스로 인증번호가 옵니다)

개인 HAI 키, 사내망, GitHub 계정은 **필요 없습니다.** 로그인하면 agent 서버가 사내 AI 를 대신 불러 주고, 회사 밖에서도 됩니다.

## 1. Node.js 설치

플러그인은 Node.js 로 돌아갑니다. 이미 있으면 건너뜁니다.

1. https://nodejs.org 에서 **LTS** 설치 파일을 받습니다.
2. 받은 파일을 열고 **다음**만 눌러 설치합니다.
3. Claude Code 를 완전히 껐다가 다시 켭니다.

Windows 에서 검은 창이 편하면 cmd 나 PowerShell 에 `winget install OpenJS.NodeJS.LTS` 한 줄로도 됩니다.

> Node.js 가 없으면 보호 기능이 돌지 못해 **파일 읽기·명령이 모두 막힙니다.** 원본이 새지 않게
> 일부러 막는 것이니, Node.js 를 설치하면 풀립니다.

## 2. 플러그인 설치

Claude Code 입력창에 아래 문장을 그대로 붙여넣습니다. 설치와 자동 업데이트 설정을 Claude 가 대신 합니다.

```text
https://agent.hecto.co.kr/plugin 에 적힌 대로 헥토 플러그인을 설치해줘
```

직접 입력하려면 `/plugin marketplace add https://agent.hecto.co.kr/plugin/marketplace.json` 다음에 `/plugin install hai@hectoadmin` 을 넣습니다. 같은 곳에서 사내 앱 개발 규칙(`aef`)·헥토 디자인(`hecto-design`)도 받을 수 있습니다. 설치가 끝나면 Claude Code 를 다시 켭니다.

## 3. 로그인

Claude Code 에 이렇게 말합니다.

```text
hai 로그인해줘
```

1. 브라우저가 열리면 헥토 이메일을 넣습니다.
2. 웍스로 온 인증번호를 넣습니다.
3. "로그인되었습니다"가 나오면 창을 닫고 Claude Code 로 돌아갑니다.

로그인은 기간 제한 없이 유지됩니다. 로그아웃(`hai 로그아웃해줘`)·퇴사·관리자 차단 때만 끊깁니다.

## 4. 설정 (선택)

`/plugin configure hai@hectoadmin` 에서 바꿉니다. 모두 비워 둬도 됩니다.

| 설정 | 넣을 값 |
|---|---|
| HAI API 키 | 보통 비워 둡니다. 넣으면 로그인하지 않았을 때 사내망에서 게이트웨이로 바로 부릅니다 |
| 보호 폴더 (권장) | Claude 가 직접 열면 안 되는 폴더. 쉼표로 여러 개. 예: `~/Documents/인사, ~/Documents/계약`. Windows 는 탐색기 주소 그대로(`C:\Users\이름\Documents\인사`) 넣어도 됩니다 |
| 원문 결과 폴더 | 받아쓰기·OCR 원문을 모을 곳. 비우면 내 문서 폴더의 `HAI 원문`(Windows 에서 문서가 OneDrive 에 있으면 그곳) |
| 가리지 않을 이메일 도메인 | 업무 메일은 그대로 두려면 `hecto.co.kr`. 비우면 이메일을 전부 가립니다 |
| 내 이름·별칭 | 할 일 정리에서 '나'로 볼 이름. 로그인 이름·주소는 자동이라 보통 비워 둡니다. 회의록에 영문 이름·별명으로 적히면 쉼표로 적습니다 |

## 5. 확인

```text
/hai:guide
```

연결 상태(로그인·서비스별)를 점검하고 할 수 있는 일을 표로 보여 줍니다. "됨"이 나오면 준비 끝입니다.

## 6. (권장) 더 확실하게 막기

```text
/hai:protect
```

보호 폴더를 한 겹 더 막습니다. 바꿀 설정을 먼저 보여 주고, "예"라고 해야 바꿉니다.

- **Mac**: 운영체제가 그 폴더 읽기 자체를 막습니다(샌드박스). 명령을 어떻게 써도 열리지 않습니다.
- **Windows**: 샌드박스가 없어 Claude Code 의 기본 도구 차단 규칙을 더합니다. 자세한 내용은 [가리기와 보호](/privacy#windows-에서-지킬-것)를 보세요.

## 새 버전으로 바꾸기

자동으로 받습니다. Claude Code 를 쓰는 중에 새 판을 받아 두고, 다시 시작하면 적용됩니다. 바로 바꾸고 싶으면:

```text
/plugin marketplace update hectoadmin
/plugin update hai@hectoadmin
/reload-plugins
```
