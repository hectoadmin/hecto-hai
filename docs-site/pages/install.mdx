# 설치

**키를 받고, Node.js 를 깔고, Claude Code 에 두 줄을 입력하면 끝입니다.** Windows(WSL 없이)와 Mac 모두 됩니다.

준비물:

- Claude Code 2.1.295 이상
- 사내망(또는 허용된 IP) — HAI 는 사내에서만 연결됩니다
- 헥토 이메일 — HAI 키를 받을 때 씁니다
- 이 저장소(hectoadmin/hecto-hai)를 볼 수 있는 GitHub 계정 — 비공개 저장소라 권한이 없으면 담당자에게 요청하세요

## 1. HAI 키 받기

1. HAI 포털에 들어갑니다. 주소는 사내 공지나, 플러그인 설치 때 나오는 키 입력 칸 설명에 있습니다.
2. 헥토 이메일로 회원가입하고 로그인합니다.
3. 오른쪽 위 **API 키 관리** → **새 키 발급**. `hai-` 로 시작하는 키가 나옵니다.

키는 개인용입니다. 남에게 주거나 메신저에 붙여 넣지 마세요.

## 2. Node.js 설치

플러그인은 Node.js 로 돌아갑니다. 이미 있으면 건너뜁니다.

**Windows** — 시작 메뉴에서 PowerShell 을 열고:

```text
winget install OpenJS.NodeJS.LTS
```

**Mac** — https://nodejs.org 에서 LTS 를 받아 설치합니다(또는 `brew install node`).

설치한 뒤 **Claude Code 를 다시 시작**하세요. Git Bash 는 없어도 됩니다(Windows 에서는 Claude 가 PowerShell 을 씁니다).

> Node.js 가 없으면 보호 기능이 돌지 못해 **파일 읽기·명령이 모두 막힙니다.** 원본이 새지 않게
> 일부러 막는 것이니, Node.js 를 설치하면 풀립니다.

## 3. 플러그인 설치

Claude Code 입력창에 차례로 입력합니다.

```text
/plugin marketplace add hectoadmin/hecto-hai
/plugin install hai@hecto
```

1. 첫 줄은 "HAI 플러그인이 들어 있는 가게를 등록해"라는 뜻입니다.
2. 둘째 줄은 "거기서 hai 를 설치해"입니다.

## 4. 설정 넣기

설치하면 설정을 묻습니다.

| 설정 | 넣을 값 |
|---|---|
| HAI API 키 (필수) | 1에서 받은 키. 비밀 값으로 따로 저장됩니다 |
| 보호 폴더 (선택, 권장) | Claude 가 직접 열면 안 되는 폴더. 쉼표로 여러 개. 예: `~/Documents/인사, ~/Documents/계약`. Windows 는 탐색기 주소 그대로(`C:\Users\이름\Documents\인사`) 넣어도 됩니다 |
| 원문 결과 폴더 (선택) | 받아쓰기·OCR 원문을 모을 곳. 비우면 내 문서 폴더의 `HAI 원문`(Windows 에서 문서가 OneDrive 에 있으면 그곳) |
| 가리지 않을 이메일 도메인 (선택) | 업무 메일은 그대로 두려면 `hecto.co.kr`. 비우면 이메일을 전부 가립니다 |

나중에 바꾸려면 `/plugin` → hai → 설정입니다.

**Claude Code 를 다시 시작**하면 적용됩니다.

## 5. 확인

```text
/hai:guide
```

연결 상태(키·사내망·서비스별)를 점검하고 할 수 있는 일을 표로 보여 줍니다. "연결됨"이 나오면 준비 끝입니다.

## 6. (권장) 더 확실하게 막기

```text
/hai:protect
```

보호 폴더를 한 겹 더 막습니다. 바꿀 설정을 먼저 보여 주고, "예"라고 해야 바꿉니다.

- **Mac**: 운영체제가 그 폴더 읽기 자체를 막습니다(샌드박스). 명령을 어떻게 써도 열리지 않습니다.
- **Windows**: 샌드박스가 없어 Claude Code 의 기본 도구 차단 규칙을 더합니다. 자세한 내용은 [가리기와 보호](/privacy#windows-에서-지킬-것)를 보세요.

## 새 버전으로 바꾸기

```text
/plugin marketplace update hecto
/plugin update hai@hecto
/reload-plugins
```
