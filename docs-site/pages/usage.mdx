# 따라 하기

**하고 싶은 일을 골라 아래 문장을 그대로 말해 보세요.** 파일 경로는 탐색기·Finder 에서 복사해 붙여 넣으면 됩니다.

## 민감한 문서 요약·조항 찾기

```text
임대차계약서.pdf 를 HAI 로만 읽고 해지 조건이랑 위약금 정리해줘
```

사내 AI 가 원문을 읽고 답만 돌려줍니다. Claude 는 원문을 보지 않습니다. 답에 남은 개인정보도 가려서 옵니다.

## 개인정보를 가리고 Claude 와 작업

```text
인사평가.docx 를 가려서 읽고 팀장 보고용 요약 초안 써줘
```

이름·연락처가 `[이름1]`·`[휴대전화1]` 로 바뀐 글을 Claude 가 받아 초안을 씁니다. 같은 사람은 문서 전체에서 같은 번호입니다.

더 가리고 싶으면 이렇게 덧붙입니다.

```text
거래처명이랑 계약 금액도 가려줘
```

## 엑셀 명단 집계

```text
주차등록.xlsx 가려서 읽고 부서별 인원 세줘
```

머리글이 성명·연락처·차량번호 같은 열은 칸 전체를 가립니다. **개수·합계는 Claude 가 셉니다** — 사내 AI 는 긴 표를 세는 데 약합니다.

## 회의 녹음 → 회의록

```text
/hai:minutes 회의녹음.m4a 김부장 박과장 헥토라이트
```

녹음은 사내 AI 만 듣고, Claude 는 회의록(이름 가림)만 봅니다. 뒤에 붙인 이름·제품명은 받아쓰기 정확도를 높여 줍니다. 전화·상담 녹음이면 "전화 녹음이야"라고 덧붙이세요.

- 녹음 형식: m4a·mp3·wav·ogg·flac·mp4 (60분까지). m4a·mp4 는 Windows·Mac 내장 기능으로 바꿔서 보냅니다.
- 마지막에 실명으로 저장할지 묻습니다.

## 스캔 계약서·사진 읽기

```text
스캔본.pdf 에서 계약 기간이랑 계약 상대만 뽑아줘
```

글자가 이미지인 쪽은 사내 AI 의 OCR(표·레이아웃 인식)로 읽습니다.

## 스캔본을 고칠 수 있는 워드로

```text
스캔본.pdf 워드 파일로 바꿔줘
```

여러 쪽이면 쪽 경계에서 잘린 표를 이어 붙인 워드 파일 하나로 만듭니다. 결과는 원문 결과 폴더에 저장되고, Claude 는 열지 않습니다.

## 화면 캡처를 파일 없이 읽기

저장하는 순간 DRM(문서 암호화)이 걸리는 PC 라면 캡처를 파일로 만들지 말고 클립보드에 둔 채 씁니다.

1. 캡처합니다(Windows: Win+Shift+S, Mac: Cmd+Ctrl+Shift+4).
2. **Claude 창에 붙여 넣지 않습니다.** 붙여 넣으면 캡처가 Claude 에 그대로 갑니다.
3. 이렇게 말합니다.

```text
클립보드 캡처 워드로 바꿔줘
클립보드 캡처 가려서 읽고 3행 금액을 50만 원으로 고쳐서 실명으로 저장해줘
```

캡처는 메모리로만 사내 AI 에 가고, 이름·연락처는 가려진 채 Claude 에 갑니다.

## 폴더 문서 모아 보기

```text
계약서 폴더 전부 계약 상대·만기일·자동갱신 여부 표로 만들어줘
```

파일마다 사내 AI 가 읽고 한 줄로 답하면 Claude 가 표로 정리합니다.

## 폴더 파일 분류표

```
/hai:files ~/Documents/계약
```

하위 폴더까지 읽어 종류·날짜·상대방·내용을 표로 만듭니다. 기준을 말하면 그 기준으로 나눕니다("거래처별로", "2026년 것만"). 400개까지 다루고, 파일은 옮기거나 지우지 않습니다. 사내 AI 가 읽은 것이라 중요한 문서는 직접 확인하세요.

## 내 문서에서 뜻으로 찾기

```text
~/Documents/계약 에서 임대료 올리는 조항 찾아줘
```

단어가 달라도("차임 증액") 뜻이 가까운 구절을 찾습니다. 처음엔 색인에 시간이 걸리고, 다음부터는 바뀐 파일만 다시 읽습니다.

## 사진·차트 설명

```text
이 사진 뭐가 문제인지 HAI 한테 물어봐줘
```

## 결과를 실명으로 저장

```text
방금 초안을 실명으로 바꿔서 바탕화면에 보고서.md 로 저장해줘
```

자리표시를 원래 값으로 바꿔 **내 PC 파일로만** 저장합니다. Claude 는 원래 값을 보지 않고, 저장한 파일도 다시 열지 못합니다. 확인은 직접 여세요.

## 메일·메신저·캘린더·그룹웨어 읽기

크롬 헥토 에이전트 확장이 필요합니다. 사내 AI 가 뒤쪽 탭에서 화면을 읽고, Claude 에는 답만 줍니다. 보던 화면은 그대로이고, 끝나면 탭이 닫힙니다.

```
오늘 안 읽은 메일의 보낸 사람과 제목을 정리해줘
그룹웨어 결재함에 뭐 와 있어?
메일이랑 그룹웨어 열어 둬
```

읽기 전용이라 저장·보내기·승인은 실행되지 않습니다. 안 읽은 메일을 열면 읽음으로 바뀔 수 있습니다. 처음 한 번은 그 사이트에서 확장 패널의 "이 사이트 허용"을 눌러 주세요.

## 오늘 할 일 한눈에

```
/hai:brief
```

일정·결재함·메일·메신저를 차례로 읽어 할 일부터 정리합니다. 메일과 대화 내용은 사내 AI 가 읽고, Claude 에는 요약만 갑니다. 매일 받으려면 `/hai:schedule 평일 아침 8시 반에 브리핑해줘`.

## 웍스 대화 요약

```
/hai:works
```

안 읽은 방을 골라 방별 요약과 할 일을 정리합니다. **방을 열면 읽음으로 바뀝니다.** 특정 방만 원하면 "○○방 오늘 뭐라고 했어?"라고 말합니다.

## 할 일 정리

```
할 일 정리해줘
내 할 일 뭐 있어?
그거 끝났어
```

메일·대화·회의록에서 내가 할 일, 남이 할 일, 확인할 일을 나눠 이 PC 에 저장합니다. 끝낸 일은 말로 닫습니다.

- 인용된 이전 메일은 빼고, 사내 AI 가 낸 근거 문장이 받은 글에 실제로 있어야 저장합니다(지어낸 일이 들어가지 않게).
- 내가 부탁한 일은 남이 할 일로, 상대가 "하겠습니다" 한 일은 기다리는 일로 나눕니다. 여러 사람에게 보낸 전체 안내는 뺍니다.
- 기한이 지난 일과, 같은 메일 스레드에 내 답장·상대의 완료 답이 온 일은 표시만 합니다. 닫는 것은 직접 말합니다.
- 회의록에 내 이름이 다르게 적히면(영문 이름·별명) 설정의 **내 이름·별칭**에 적어 두세요.

## 규칙 알림

```
/hai:watch 긴급 메일 오면 알려줘
```

정해진 간격으로 확인하다가 규칙에 걸리면 나에게 웍스 봇 DM 을 보냅니다. 사내 AI 가 읽어 판단하므로 놓칠 수 있습니다. 놓치면 안 되는 경보로 쓰지 마세요.

## 정해진 시간에 돌리기

Claude 데스크톱 앱에서 말합니다.

```
/hai:schedule 매일 아침 8시 반에 안 읽은 메일 요약해줘
```

- 확장 패널의 "닫혀 있어도 바로 실행"을 켜 둡니다.
- 예약 시각에 PC·Claude 앱이 켜져 있어야 합니다. 크롬은 꺼져 있으면 플러그인이 켭니다.
- 크롬이 꺼졌거나, 로그인이 풀렸거나, 확인을 기다리면 웍스 봇 DM 이 옵니다.
- 상신·승인·삭제·제출은 예약이어도 크롬에서 직접 확인합니다.

## 되는 파일

| 종류 | 형식 |
|---|---|
| 문서 | txt·md·csv(UTF-8·EUC-KR)·json·html·pdf·docx·xlsx·hwpx |
| 사진 | png·jpg·tif·webp |
| 녹음 | wav·mp3·ogg·flac·m4a·mp4 (60분까지) |

옛 형식(hwp·xls·doc)은 한글·엑셀·워드에서 hwpx·xlsx·docx 나 PDF 로 다시 저장해서 쓰세요.
