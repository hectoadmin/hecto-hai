# 명령과 도구

**처음에는 `/hai:guide` 하나만 알아도 됩니다.** 나머지는 평소처럼 말하면 Claude 가 알맞은 도구를 고릅니다.

## 명령

| 명령 | 언제 쓰나요 |
|---|---|
| `/hai:guide` | 처음 쓸 때, 안 될 때 — 연결 점검과 할 수 있는 일 안내 |
| `/hai:doc <파일> [할 일]` | 민감한 문서·스캔본·사진 하나를 처리할 때 |
| `/hai:minutes <녹음> [이름·용어]` | 회의 녹음으로 회의록을 만들 때 |
| `/hai:protect` | 보호 폴더를 한 겹 더 막을 때(설정을 바꾸기 전에 묻습니다) |
| `/hai:browser` | 사내 화면 읽기·맡기기 안내 |
| `/hai:brief` | 일정·결재·메일·메신저를 읽어 오늘 할 일을 정리할 때 |
| `/hai:works` | 안 읽은 웍스 대화방을 요약할 때(방을 열면 읽음 처리) |
| `/hai:todo` | 메일·대화에서 할 일을 뽑고 관리할 때 |
| `/hai:watch` | 규칙에 걸리면 나에게 봇 DM 을 받을 때 |
| `/hai:files <폴더>` | 폴더 파일을 읽어 분류표를 만들거나 찾을 때(파일은 옮기지 않음) |
| `/hai:schedule` | 사내 화면 일을 정해진 시간에 돌게 예약(Claude 데스크톱 앱) |

민감한 파일 경로를 주거나 "가려서", "HAI 로", "개인정보" 같은 말을 하면, 따로 명령하지 않아도 Claude 가 원본 대신 HAI 도구를 씁니다.

## 도구 (Claude 가 쓰는 것)

| 도구 | 하는 일 | Claude 에 가는 것 |
|---|---|---|
| `hai_ask_file` | 파일 하나를 사내 AI 만 읽고 답 | 답(가림) |
| `hai_ask_files` | 여러 파일에 같은 질문 | 파일별 답(가림) |
| `hai_mask_file` | 파일을 가린 글로 바꿔 줌 | 가린 본문 |
| `hai_restore` | 자리표시를 실명으로 바꿔 내 PC 에 저장 | 저장 위치만 |
| `hai_transcribe` | 녹음 받아쓰기 파일 만들기 | 저장 위치만 |
| `hai_ocr` | 스캔·사진·클립보드 캡처 → Markdown·워드 파일 | 저장 위치만 |
| `hai_search` | 폴더 문서에서 뜻으로 찾기 | 찾은 구절(가림) |
| `hai_chat` | 사내 AI 에 바로 묻기(다듬기·번역·사진 설명) | 답 |
| `hai_status` | 로그인(또는 키)·서비스별 연결, 보호 설정 점검 | 상태 |
| `hai_login` · `hai_logout` | 헥토 이메일로 로그인·로그아웃(키 없이 사내 AI) | 로그인 |
| `agent_read` | 메일·메신저·캘린더·그룹웨어 화면을 사내 AI 가 뒤쪽 탭에서 읽고 답한다(읽기 전용) | 사내 AI 의 답(가림) |
| `agent_recipes` · `agent_run` · `agent_status` · `agent_answer` | 저장한 작업이나 글로 맡긴 일을 내 크롬에서 실행·진행 보기·확인에 답 | 단계 이름·확인 질문·결과 문장(가림) |
| `hai_todo` | 이 PC 에만 두는 할 일 목록 보기·더하기·닫기 | 할 일 글 |
| `hai_notify` | 나에게 웍스 봇 DM(다른 사람에게는 못 보냄) | 없음 |
| `hai_folder_info` | 폴더의 파일 수·형식·기간만 세기(내용을 읽지 않음) | 개수 |
| `agent_open` | 평소 쓰는 크롬을 켜고 사이트를 새 탭으로 연다 | 없음 |

`hai_chat` 에 넣는 글은 이미 Claude 가 본 글입니다. 민감한 파일은 `hai_ask_file` 로 읽습니다.

크롬 작업은 확장에 같은 계정으로 로그인돼 있어야 합니다. 크롬이 꺼져 있으면 플러그인이 켭니다. 화면은 사내 AI 만 보고 Claude 에는 결과만 갑니다. 저장·임시 저장 같은 확인은 대화에서 답할 수 있고, 상신·승인·삭제·제출·이동·파일 고르기는 크롬 패널에서만 확인합니다(Claude 가 대신 승인할 수 없음).

`hai_ask_file` · `hai_mask_file` · `hai_ocr` 은 파일 경로 대신 `clipboard: true` 로 클립보드의 캡처를 읽습니다(파일을 만들지 않음).
