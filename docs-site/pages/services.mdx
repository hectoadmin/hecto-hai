# 사내 AI 서비스

**HAI 게이트웨이의 서비스 여섯 가지를 플러그인이 알아서 골라 씁니다.** 어떤 서비스를 쓸지 직접 고를 필요는 없습니다.

| 서비스 | 모델 | 이 플러그인에서 하는 일 |
|---|---|---|
| Qwen | Qwen3.8-27B | 문서 읽고 답하기, 이름·주소 찾기, 회의록 쓰기, 분석 |
| Gemma | Gemma 4 31B | 사진·차트 이해, 일반 대화·요약 |
| KURE | KURE-v1 (한국어 임베딩) | 내 문서에서 뜻으로 찾기 |
| Whisper | Whisper large-v3 | 회의·일반 녹음 받아쓰기 |
| Qwen3-ASR | Qwen3-ASR | 전화·상담·잡음 많은 녹음 받아쓰기 |
| PaddleOCR | PaddleOCR (표·레이아웃) | 스캔 PDF·사진 글자 뽑기, 워드 변환 |

- 모두 사내 게이트웨이(`hai-gateway.idc.hectoai.co.kr`)로만 연결됩니다. 키와 사내망이 없으면 동작하지 않습니다.
- 연결 상태는 `/hai:guide` 또는 "HAI 연결 점검해줘"로 서비스별로 확인할 수 있습니다.
- 한도: 요청 하나 50MB, 녹음 60분·200MB, 응답 대기 최대 5분.
