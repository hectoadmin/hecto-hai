> 비유하면, 민감한 서류는 **사내 비서(HAI)만 원본을 읽고**, 바깥 전문가(Claude)에게는
> 이름과 연락처를 지운 사본만 건네는 방식입니다. 전문가는 사본으로 보고서를 쓰고,
> 실명은 마지막에 내 PC 에서만 다시 채웁니다.

## 무엇을 해 주나요?

Claude Code 에 한국어로 말하면 됩니다.

```text
임대차계약서.pdf 를 HAI 로만 읽고 해지 조건 정리해줘
인사평가.docx 를 가려서 읽고 보고서 초안 써줘
/hai:minutes 회의녹음.m4a
```

<Diagram name="home-flow" alt="내 PC 파일의 원문은 사내 AI 만 읽고, Claude 에는 가린 글과 답만 간다. 실명 결과는 내 PC 에만 저장되고, Claude 가 원본을 직접 열려 하면 보호 훅이 막는다" />

1. 원본 파일(문서·스캔본·녹음)은 **사내 AI(HAI)만** 읽습니다.
2. 사내 AI 가 이름·연락처·주민번호 같은 개인정보를 `[이름1]` 같은 자리표시로 바꿉니다.
3. Claude 는 가린 글로 요약·초안·집계를 합니다.
4. 실명이 필요하면 결과를 **내 PC 에만** 실명으로 저장합니다. Claude 는 그 파일도 열지 못합니다.

## 누구를 위한 건가요?

- 보안 때문에 민감한 파일을 Claude 에 넣지 못하던 분
- 사내 AI(HAI)는 있는데 어떻게 써야 할지 모르던 분
- 회의 녹음·스캔 계약서·엑셀 명단을 자주 다루는 분

개발 지식은 필요 없습니다. 설치만 하면 평소처럼 Claude 에 말하면 됩니다.

## 지키는 것

- **원문은 사내 AI 만 읽습니다.** 사내망 밖으로 원문이 나가지 않습니다.
- **키는 각자 발급받습니다.** 키가 없거나 사내망이 아니면 동작하지 않습니다.
- **Claude 가 원본을 직접 열면 막습니다.** 보호 폴더를 정해 두면 실수로도 열지 못합니다.
- **가리다 만 글은 넘기지 않습니다.** 사내 AI 가 응답하지 않으면 실패로 멈춥니다.

## 시작하기

1. [설치](/install) — Windows·Mac 모두 됩니다. 10분이면 끝납니다.
2. Claude Code 에서 `/hai:guide` 라고 입력하면 연결을 점검하고 할 수 있는 일을 알려 줍니다.
3. [따라 하기](/usage)에서 하고 싶은 일을 골라 그대로 말해 보세요.
