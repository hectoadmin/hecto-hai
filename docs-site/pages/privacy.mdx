# 가리기와 보호

**원본을 지키는 중심은 "원문은 사내 AI 만 읽는다"입니다.** 가리기와 보호 훅은 그 위에 얹은 장치입니다.

## 무엇을, 어떤 순서로 가리나

<Diagram name="masking-steps" alt="표 열 가리기, 모양으로 가리기, 사내 AI 가 찾기, 남은 것 검사 순서. 깨끗하면 자리표시로 Claude 에게, 남으면 넘기지 않고 실패" />

| 순서 | 무엇을 | 예 |
|---|---|---|
| 1. 표 열 | 머리글이 성명·사번·연락처·주소·차량번호·계좌·생년월일인 열은 칸 전체 | 엑셀 명단 |
| 2. 모양 | 주민등록번호(뒷자리 * 포함), 휴대전화·전화(+82·괄호·전각 숫자), 이메일, 계좌, 카드, 여권, 운전면허 | 본문 속 번호 |
| 3. 사내 AI | 사람 이름, 주소, 생년월일, 사번·회원번호 같은 식별번호 | 문장 속 이름 |
| 4. 검사 | 위 단계에서 놓친 번호 모양이 남았는지 다시 확인 | 남으면 실패 |

- 같은 값은 문서 전체에서 같은 자리표시(`[이름1]`)가 됩니다. 원래 값은 메모리에만 있고 Claude 에 가지 않습니다.
- 사내 AI 가 응답하지 않으면 **가리다 만 글을 넘기지 않고 실패**합니다.
- 금액·날짜·일반 숫자는 그대로 둡니다(지나치게 가리지 않게).
- 자동이라 **놓칠 수 있습니다.** 중요한 문서는 결과를 한 번 훑어보고, 더 가릴 것을 말해 주세요.

## 원본을 지키는 세 겹

<Diagram name="protect-layers" alt="1. HAI 도구로 원문은 사내 AI 만 읽음. 2. 보호 훅이 Read·Grep·Bash·PowerShell 로 보호 폴더를 열면 막음. 3. Mac·Linux 는 샌드박스, Windows 는 기본 도구 차단 규칙과 명령 실행 확인" />

1. **HAI 도구** — 원문은 사내 AI 만 읽습니다. 가장 중요한 겹입니다.
2. **보호 훅** — Claude 가 보호 폴더나 원문 결과 파일을 Read·Grep·Bash·PowerShell 로 열려 하면 막고 HAI 도구를 쓰라고 돌려보냅니다.
   - 따옴표·와일드카드·변수·명령 치환·스크립트 파일 안의 경로까지 풀어서 판단합니다.
   - 무엇을 여는지 알 수 없게 만든 명령(인코딩한 글자·eval·iex·base64)은 막습니다.
   - 다만 명령 글자를 보고 판단하는 **안전망**이라, 실행 중에 경로를 만들어 내는 코드까지 완벽하게 막지는 못합니다.
3. **운영체제 수준** — `/hai:protect` 로 켭니다.
   - Mac·Linux: 샌드박스가 그 폴더 읽기 자체를 막습니다. 2번의 한계가 없습니다.
   - Windows: 샌드박스가 없습니다. 아래를 함께 지켜 주세요.

## Windows 에서 지킬 것

Windows 에는 운영체제 수준 차단이 없어 Mac 보다 한 겹 약합니다. 세 가지만 지키면 충분합니다.

- Claude 가 명령을 실행하겠다고 물을 때 **"항상 허용"을 누르지 말고** 한 번씩 확인하세요. 인사·계약 폴더 경로가 보이면 거절합니다.
- 인사·계약 폴더 **안에서** Claude Code 를 시작하지 마세요. 작업 폴더는 따로 둡니다.
- `/hai:protect` 로 기본 도구 차단 규칙을 더하세요.

## 원문 결과 폴더

받아쓰기·OCR·실명 복원 결과(가리지 않은 원문)는 한곳(기본: 내 문서 폴더의 `HAI 원문`)에 모입니다.

- Claude 는 이 폴더의 **파일 이름은 볼 수 있지만 내용은 열지 못합니다.**
- 원문 결과 파일은 장부(`~/.hai-mcp/raw-files.log`, 경로만)에도 올라, 다른 곳에 저장해도 Claude 가 다시 열지 못합니다.
