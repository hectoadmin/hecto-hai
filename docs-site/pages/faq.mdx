# 문제 해결

**먼저 `/hai:guide` 를 입력하세요.** 연결을 점검하고 원인을 알려 줍니다.

## HAI 도구가 아예 안 보여요

둘 중 하나입니다.

- **키를 아직 안 넣었습니다.** 키가 없으면 Claude Code 가 서버를 띄우지 않습니다. `/plugin` → hai → 설정에서 키를 넣고 Claude Code 를 다시 시작하세요.
- **Node.js 가 없습니다.** [설치 2단계](/install#2-nodejs-설치)를 하고 다시 시작하세요.

어느 쪽인지 모르겠으면 `/mcp` 화면에서 hai 의 오류를 보세요.

## 파일 읽기·명령이 모두 "훅 오류"로 막혀요

보호 훅이 돌지 못한 것입니다(대개 Node.js 없음). 원본이 새지 않게 안전하게 막아 둔 상태입니다. Node.js 를 설치하고 다시 시작하면 풀립니다.

## "보호 폴더입니다"라며 막혀요

정상입니다. 그 파일은 HAI 도구로 읽어야 합니다. "이 파일 HAI 로 읽어줘"라고 말하세요. 보호 폴더를 품은 넓은 폴더를 검색하다 막혔다면, 보호 폴더 밖의 더 좁은 폴더를 지정하세요.

## 키가 틀렸다고 나와요

포털에서 새 키를 발급해 `/plugin` → hai → 설정에 다시 넣으세요.

## 연결이 안 돼요

사내망(또는 허용된 IP)에서만 됩니다. 재택이면 사내망 접속 방법을 확인하세요.

## 녹음 변환을 못 했다고 나와요

m4a·mp4 는 Windows·Mac 내장 기능으로 바꿉니다. 그래도 안 되면 녹음기 앱에서 mp3·wav 로 저장하거나 ffmpeg 를 설치하세요(Windows: `winget install Gyan.FFmpeg`).

## 결과가 길어서 파일로 저장됐다고 나와요

가린 결과가 길면 파일로 저장합니다. Claude 가 그 파일(가린 글)을 나눠 읽습니다. 그대로 이어서 요청하면 됩니다.

## 가리기가 이름을 놓쳤어요

"이 사람 이름도 가려줘", "거래처명도 가려줘"처럼 말하면 그 유형을 더해 다시 가립니다.

## 실명으로 되돌리기가 안 돼요

되돌리기는 같은 세션(12시간) 안에서만 됩니다. 오래됐으면 원본을 다시 가린 뒤 작업하세요.
